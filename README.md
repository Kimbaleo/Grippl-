# Grippl 🥨

Da bayerische Schimpfwort-Generator: Namen eingeben, auf **„Schimpf!“** drücken –
und scho kriagt ma a zünftige Beschimpfung in bayerischer Mundart, samt
Übersetzung fürs Preißn.

## Starten

Einfach `index.html` im Browser öffnen. Keine Installation, kein Build.

## Wia's geht

- Adjektiv-Stamm + Hauptwort werden zufällig kombiniert, die Endung passt
  sich ans Geschlecht an (*damischa Depp*, *damische Funsn*, *damischs Rindviech*).
- Dazu a zufällige Satzvorlage und ab und zu a Nachsatz („Schleich di!“).
- Enter im Namensfeld funktioniert genauso wia da Knopf; „Kopiern“ legt den
  Spruch in die Zwischenablage.

Ois nur a Gaudi – ned bös gmoant!
